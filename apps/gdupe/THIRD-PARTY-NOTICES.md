# Third-party notices

gdupe statically links third-party software into `gdupe.exe`. The complete
license or public-domain text distributed with each component is included under
`licenses/` in the portable package. Source-identification files are included
where gdupe builds a source-pinned dependency with local Windows portability
adaptations.
